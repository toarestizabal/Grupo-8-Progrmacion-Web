# PixelForge Games

Proyecto de Programación Web.

Para abrir la página hay que ejecutar el archivo index.html con Live Server.

La página tiene registro, inicio de sesión, recuperación de contraseña, carrito de
compras y administración de productos, usuarios, inventario y pedidos.

Los datos se guardan en el navegador porque el proyecto no utiliza base de datos.
El pago es solamente una simulación.


Cuentas para probar la página:

Administrador: admin@pixelforge.cl / Admin1!
